# تقویم هوشمند 📅

> همه‌ی تاریخ‌ها، همیشه همراه شما

اپلیکیشن کامل تقویم شمسی اندروید با Kotlin و Jetpack Compose — آماده برای انتشار در کافه‌بازار.

## ✨ امکانات

- **تقویم شمسی کامل** با نمایش ماهانه (اسکرول روان بین ماه‌ها)
- **نام کامل روزهای هفته** در سربرگ تقویم: شنبه، یکشنبه، دوشنبه، سه‌شنبه، چهارشنبه، پنج‌شنبه، جمعه
- **اذان و اوقات شرعی آفلاین** — محاسبه نجومی دقیق (روش ژئوفیزیک تهران یا سازمان جهانی اسلام) برای ۵۰+ شهر، شمارش معکوس اذان بعدی، پخش اذان داخلی و زنگ خودکار اذان با اعلان
- **قبله‌نما** — قطب‌نمای زنده با حسگر گوشی، فلش جهت کعبه معظم، انتخاب شهر و نمایش زاویه قبله از شمال
- **اعلان دائمی تاریخ امروز** — تاریخ شمسی/قمری/میلادی همیشه در نوار وضعیت (قابل خاموش‌کردن)، تازه‌سازی خودکار نیمه‌شب
- **تعطیلات رسمی و مناسبت‌های ایران** — دقیق برای سال‌های ۱۴۰۴ و ۱۴۰۵ بر اساس تقویم رسمی، الگوریتمی برای سایر سال‌ها
- **تبدیل تاریخ** شمسی ↔ میلادی ↔ قمری به‌صورت هم‌زمان
- **ثبت رویداد و یادآور** با اعلان دقیق، صدای دلخواه، لرزش و تکرار روزانه/هفتگی/ماهانه/سالانه
- **جست‌وجو** بین رویدادهای ثبت‌شده
- **حالت روشن و تاریک** + ۵ پوسته رنگی (آبی، سبز، بنفش، نارنجی، سرمه‌ای)
- **پشتیبان‌گیری و بازیابی** رویدادها با فایل JSON
- **کاملاً آفلاین** — بدون هیچ مجوز اینترنتی و بدون جمع‌آوری داده

## 🔧 اجرا

1. **Android Studio** (Ladybug یا جدیدتر) را باز کنید و پوشه پروژه را Import کنید.
2. صبر کنید تا Gradle سینک شود (نیاز به JDK 17 — خود Studio همراه دارد).
3. `Run ▶` روی دستگاه مجازی یا گوشی.

ساخت از خط فرمان:

```bash
./gradlew assembleDebug        # نسخه تست
./gradlew test                 # اجرای تست‌های واحد (تبدیل تاریخ)
./gradlew assembleRelease      # نسخه انتشار (نیاز به امضا)
```

## ✍️ امضا و ساخت فایل انتشار

```bash
# ساخت کلید امضا (فقط یک بار — این فایل را گم نکنید!)
keytool -genkey -v -keystore hooshmand-calendar.jks -keyalg RSA -keysize 2048 -validity 10000 -alias hooshmand

# ساخت فایل AAB امضاشده
./gradlew bundleRelease
# خروجی: app/build/outputs/bundle/release/app-release.aab
```

## 📂 ساختار کد

```
app/src/main/java/ir/hooshmandcalendar/app/
├── core/                  موتور تقویم (جلالی، قمری، اعداد فارسی)
├── data/                  مناسبت‌ها + جدول رسمی ۱۴۰۴–۱۴۰۵ + شهرها
│   ├── db/                Room (رویدادها)
│   └── SettingsStore.kt   تنظیمات با DataStore
├── prayer/                اوقات شرعی آفلاین + زمان‌بند اذان
├── qibla/                 قبله‌نما (حسگر قطب‌نما + محاسبه جهت)
├── reminders/             یادآورها (AlarmManager، BootReceiver، اعلان تاریخ امروز)
├── ui/                    صفحات Compose (تقویم، رویدادها، مناسبت‌ها، اذان، قبله‌نما، تنظیمات، تبدیل)
└── AppViewModel.kt        ویومدل مشترک
```
