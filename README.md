# تقویم هوشمند — Smart Persian Calendar

تقویم کامل شمسی / قمری / میلادی برای اندروید، ساخته‌شده با Kotlin و Jetpack Compose.
کاملاً آفلاین، بدون هیچ مجوز اینترنتی و بدون جمع‌آوری هیچ داده‌ای.

A full Jalali (Persian), Hijri (Islamic) and Gregorian calendar app for Android — 100% offline, no internet permission, no data collection.

## قابلیت‌ها

- تقویم ماهانه / هفتگی / فهرستی با کشیدن انگشت بین ماه‌ها
- نمایش هم‌زمان تاریخ شمسی، قمری و میلادی به‌همراه روز هفته
- مناسبت‌های رسمی و مذهبی ایران (تعطیلات ۱۴۰۴ و ۱۴۰۵ بر اساس جدول رسمی)
- ثبت رویداد با ۸ رنگ، ساعت شروع و پایان، تکرار (روزانه / هفتگی / ماهانه / سالانه)
- یادآور رویدادها با آلارم دقیق، انتخاب زنگ سیستم و لرزش
- یادآور تولد با تکرار سالانه شمسی
- جست‌وجوی سریع در همه رویدادها
- تبدیل سه‌گانه تاریخ (شمسی / قمری / میلادی) با انتخاب روز از تقویم
- پشتیبان‌گیری و بازیابی رویدادها به‌صورت فایل JSON
- ۵ پوسته رنگی (آبی، سبز، بنفش، نارنجی، سرمه‌ای) + حالت شب کامل
- اعداد فارسی / انگلیسی قابل انتخاب، شروع هفته از شنبه
- فونت وزیرمتن و رابط کاربری تمام فارسی (راست‌به‌چپ)

## نصب

حداقل نسخه اندروید: 7.0 (API 24) — هدف: Android 15 (API 35)

1. فایل APK را از جدول بالا دانلود کنید.
2. روی فایل بزنید؛ در صورت نمایش پیام «منابع ناشناس»، اجازه نصب از همان مرورگر یا فایل‌منیجر را بدهید.
3. نصب انجام می‌شود و آیکون «تقویم هوشمند» در فهرست برنامه‌ها ظاهر می‌شود.

## حریم خصوصی

این برنامه مجوز `INTERNET` ندارد؛ یعنی هیچ داده‌ای از گوشی شما خارج نمی‌شود.
همه رویدادها و تنظیمات فقط روی خود دستگاه ذخیره می‌شوند. مجوزهای برنامه:

- `POST_NOTIFICATIONS` — نمایش یادآور رویدادها
- `SCHEDULE_EXACT_ALARM` / `USE_EXACT_ALARM` — زمان‌بندی دقیق یادآورها
- `RECEIVE_BOOT_COMPLETED` — بازیابی یادآورها پس از روشن‌شدن گوشی
- `VIBRATE` و `WAKE_LOCK` — لرزش و نمایش یادآور
